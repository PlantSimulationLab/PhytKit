# LI-600 porometer data

Part of the `phytkit` skill.

## 1. Correct the conductance

The LI-600 overestimates gsw at high conductance. `pk li600 correct` applies the Rizzo &
Bailey (2025) energy-balance correction.

```bash
pk li600 correct readings.csv --sidedness 1 --out readings_corrected.csv
```

- **Needs** the columns `gsw`, `Tref`, `Tleaf`, `rh_r`, `rh_s`, `flow`, `P_atm` and
  `E_apparent`. The LI-600 CSV export has them; the column-name row is found automatically.
- **`--sidedness`** is 1 for stomata on one side of the leaf, 2 for both. Ask the user; it
  changes the result. `--thermal-conductance` defaults to the instrument value 0.007 W °C⁻¹.
- **Output:** `summary` gives the mean and maximum overestimate in percent over the readings
  that solved, `solved` counts them, and `--out` writes the input file with `gsw_corrected`,
  `E_corrected` and corrected temperatures added.

## 2. Estimate A from conductance

`pk li600 estimate` solves A, Ci and Cc for each reading from its conductance, light and leaf
temperature and a photosynthesis parameter set:

```bash
pk fit photosynthesis aci.csv --ci-based > fit.json
pk li600 estimate readings_corrected.csv --params fit.json --out readings_with_A.csv
```

- **Needs** `gsw`, `Qamb` and `Tleaf`. `gsw_corrected` is used in place of `gsw` when present
  (`usedCorrectedGsw` in the output, `gsw_uncorrected_used` warning otherwise).
- **`--params`** takes one `pk fit` JSON result (not a batch; pass one entry of `results`), a
  CSV of fitted parameters, a Parameter/Value table, or `name = value` lines. `--set` overrides
  one value. Without `--params` the model's defaults are used, which is fine for trying the
  command but not for real estimates.
- **The model** comes from `--model`, else from the `--params` fit, else `fvcb`.
- **Other options:** `--ca` (ambient CO₂, default 420 µmol mol⁻¹), `--absorptance` (applied to
  `Qamb`, default 0.85), and `--min-gsw` (readings below it are raised to it and counted in
  `clamped`; 0 leaves them unsolved, with `readings_unsolved`).
- **gm:** a fit made with `--ci-based` is read back with no mesophyll resistance. A finite gm
  between 0 and 99 is used in series with stomatal conductance (`settings.series`).
