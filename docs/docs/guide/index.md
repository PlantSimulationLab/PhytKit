# User Guide

This guide takes you from a fresh install to fitting your own data.

If you haven't used PhytKit before, read these pages in order:

1. **[Install PhytKit](install.md)**: build the `pk` command and, if you want it, the Python package.
2. **[Your first fit](first-fit.md)**: fit an A–Ci curve from the sample data and read the result.
3. **[Using the command line](command-line.md)**: how commands, options, output and errors work.
4. **[Scripting with Python](python.md)**: the same tools from Python, plus fitting data already in memory.

Then go to **[Workflows](../workflows/index.md)** for step-by-step recipes,
such as correcting LI-600 readings or fitting pressure–volume curves. To
understand what a model or the fitter is doing, read
**[Concepts](../concepts/index.md)**.
